# 手腕舵机示数数采与推理

本文解释双轴腕从传感器、遥操作、HDF5 到 π0.5 推理的唯一坐标合同。它是本项目中文文档，
不是 OpenPI 官方原文。

## 一句话结论

J1/J2 的训练状态和动作都使用“舵机 raw 减 YAML 零位”：

```text
state_wrist  = actual_motor_raw - servo_zero_raw
action_wrist = sent_target_raw  - servo_zero_raw
sent_raw     = round(policy_action_wrist + servo_zero_raw)
```

当前零位在 `examples/ur5_twinwrist/config/poses.yaml`：

```yaml
wrist:
  coordinate: yaml_servo_zero_relative_raw
  state_order: [j1, j2]
  servo_zero_raw: [3278, 2547]
```

重新安装手腕后，只在安全标定完成后修改这两个数。不要改模型 transform 来补偿装配零位。

## 维度和例子

| 数据 | 第 1 维 | 第 2 维 | 单位 |
|---|---|---|---|
| 从腕绝对反馈 | `j1_pos` | `j2_pos` | Dynamixel raw |
| YAML 零位 | 3278 | 2547 | Dynamixel raw |
| 训练 state[6:8] | `j1_pos-3278` | `j2_pos-2547` | relative raw |
| 训练 action[6:8] | `sent_j1-3278` | `sent_j2-2547` | relative raw |

例如实际反馈是 `[3300,2500]`，保存的腕 state 是 `[22,-47]`。policy 输出 `[20,-10]` 时，
驱动先执行 NaN/Inf、过期、急停、软限位和单步检查，再发送绝对目标 `[3298,2537]`。

这里的 relative raw 是“相对坐标中的绝对位置”，不是相邻两帧之差。

## 数采路径

```text
ESP32 Enc0/Enc1
→ MasterWristReader 建立本次操作者输入零位
→ Enc0×10 raw/deg→J1，Enc1×14 raw/deg→J2
→ One-Euro + velocity/acceleration/jerk target shaper
→ WristMasterSlaveController 仲裁主腕/Ctrl/policy
→ OpenRBWrist 加 YAML servo zero 并发送绝对舵机 raw
→ GET_WRIST_STATE 直接读取 j1_pos/j2_pos
→ TeleopHardwareWorker 生成最终 action receipt
→ EpisodeRecorder 以 10 Hz 保存 qpos 和实际下发 action
```

HDF5 的 `qpos[:,6:8]` 来自实际舵机反馈，`action[:,6:8]` 来自成功下发后的命令回执。
SpaceMouse 原始轴、AS5048A 角度和未下发的候选目标都不能冒充训练 action。

## 推理路径

```text
实际 j1_pos/j2_pos - 当前 YAML 零位
→ observation.state[6:8]
→ UR5TwinWristInputs 保持 raw 数值，OpenPI pad 到 32 维
→ π0.5 输出 32 维 action chunk
→ UR5TwinWristOutputs 截取前 9 维
→ safety_filter 检查腕相对 raw 范围和单步变化
→ OpenRBWrist.set() 四舍五入并加当前 YAML 零位
→ SET_ARM_TARGET_STREAM absolute_j1 absolute_j2
```

训练和推理必须使用同一套字段顺序、同一份配置 hash 和同一个 action space 定义。零位变化时
旧数据仍是相对坐标；新机器发送时使用当前 YAML 零位。

## AS5048A 现在做什么

`enc0_deg/enc1_deg` 只保留在 `hardware_health.wrist` 中用于诊断安装、掉线和机械异常：

- 不进入 9 维 `observation.state`；
- 不进入 9 维 `action`；
- 不参与 Home；
- 不参与 START 判定；
- 不参与 policy 输出换算；
- 编码器反馈失效不能被悄悄当成舵机位置反馈。

## 关键代码和配置

| 位置 | 作用 |
|---|---|
| `config/poses.yaml` | J1/J2 `servo_zero_raw` 和顺序 |
| `config/hardware.yaml` | 主腕映射、One-Euro、舵机 profile、target shaper |
| `config/safety.yaml` | J1/J2 绝对 raw 限位、18 raw 单步上限和 Home 收敛 |
| `config/collection.yaml` | state/action 字段名与 9 维合同 |
| `controller/wrist.py` | 读舵机 raw、减/加零位、控制、Home 和 fail-closed |
| `teleop_hardware.py` | 主从腕调度和最终 action receipt |
| `local_hardware.py` | policy 真机 observation 和相对 raw action 下发 |
| `episode_recorder.py` | HDF5 零位、坐标和 raw 限位元数据 |
| `validate_dataset.py` | 数据零位、范围、NaN、长度和时间戳检查 |
| `ur5_twinwrist_policy.py` | 9→32 pad 前后的 policy transform，不做角度换算 |
